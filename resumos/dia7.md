## ⚙️ **Análise HTTP e API REST**

- **API Exemplo**: ServeRest → Documentação
- **Informação Crucial**: Base URL
- **Tipo de Documentação**: Swagger
- **Análise**: Revisar e avaliar a documentação
- **Considerações**: Identificar lacunas
- **Atenção**: Seguir as diretrizes na documentação da API

---

### Passo a Passo para Verificação da Documentação da API

- **Verificação das Rotas**:
    - **Rota de Login**:
        - Duração do token e do teste
        - Analisar as respostas durante o login
        - Notar a ausência de códigos de tratamento na documentação
    - **Rota de Usuários**:
        - Verificar os verbos utilizados e a não exigência de token
        - Observar as regras de cada verbo para elaboração de testes (ex.: input e delete)
        - Identificar a falta de códigos de tratamento, resultando em mensagens inapropriadas para o usuário

## ⚙️ **Mapa Mental**

O mapa mental, uma técnica utilizada desde os tempos de Da Vinci e aprimorada ao longo dos anos, é amplamente aplicado para análise e organização de ideias e processos. Seu objetivo principal é proporcionar uma visualização clara e estruturada do fluxo de ideias, facilitando a decomposição ou a criação de fluxos de trabalho. Utilizaremos essa abordagem para testes e fluxos de teste, pois se adapta muito bem a esse contexto.
