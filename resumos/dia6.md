## Priorização em diferentes aplicações

- Como priorizar fluxo de teste
- exemplo (**ecommerce**)
  - Qual o principal objetivo da minha aplicação?
  <br>
  - O fluxo que estou abordando bloqueia ou dificulta a realização do objetivo principal da aplicação? Se sim, o fluxo é prioritario.
  <br>
    - Ex: se eu não conseguir logar, vou conseguir comprar? não, então é prioritario
    <br>
    - Ex: se eu não conseguir adicionar produto na sacola, vou conseguir comprar? não, então é prioritario
<br>
- Exemplo ( **programa de pontos**)
  - objetivo, resgate de pontos, compra de pontos, transferencias de pontos, venda de pontos.
  - Todo o fluxo para realizar a compra tem que estar funcionando.
<br>

- Exemplo(**Telefonia**)
  - principal objetivo, autoatendimento para clientes
  - se o usuario não conseguir fazer download da segunda via de conta movel, o objetivo da aplicação esta sendo cumprido? não, fluxo prioritario
<br>
<br>

- **Cada fluxo é uma serie de pequenas tarefas**
<br>

- **Priorização dentro de demandas**

- Dentro de cada demanda, vai ser necessario especificar as demandas prioritarias

- depois de alterações, tem que testar para saber se alterações não afetaram o fluxo de compras

### Exercicio
- Escolher segmento e aplicação na internet, e criar lista de fluxos prioritários para validação

passo 1 - Apresentar a aplicação, o segmento e o objetivo principal do sistema;

Passo 2 - Elaborar lista de fluxos de validação prioritarios no sistema escopo;

Passo 3 - ordenar a lista de forma logica, para a realização de fluxos completos na aplicação

#### Steam

- objetivo, venda/distribuição de jogos e itens pertencentes a eles.

- Lista de fluxos compra de jogos 
<br>
- Consigo fazer cadastro?
- Consigo acessar a loja de jogos?
- Consigo Pesquisar o jogo?
- Consigo adicionar jogos no carrinho?
- Consigo escolher o metodo de pagamento?
- Consigo Realizar o pagamento?
- O produto foi adicionado a minha biblioteca de jogos?

- Lista de fluxos Compra de itens
<br>
- Consigo acessar o mercado da Steam?
- Consigo Pesquisar o item?
- Consigo adicionar o item no carrinho?
- Consigo escolher o metodo de pagamento?
- Consigo Realizar o pagamento?
- O item foi adicionado no meu inventario?
